          About

          Tilbi is a powerful clipboard manager that helps you manage your clipboard history efficiently. With features like text editing, screenshot capture, and quick access to your clipboard history, Tilbi makes your workflow smoother.

          Help & Manual

          📋 Getting Started

          Tilbi is a comprehensive clipboard manager with multiple features to enhance your productivity.

          📝 History Tab

          Purpose: Stores your recent clipboard history

          • Click any item to copy it to clipboard and paste it
          • Pin icon (📌): Save important items permanently
          • Edit icon (✏️): Modify text before copying
          • Delete icon (🗑️): Remove unwanted items
          • Screener icon (📸): Move items to Screener tab
          • Search: Use the search bar to find specific content

          📌 Pinned Tab

          Purpose: Permanent storage for frequently used items

          • Pin items from History tab to keep them permanently
          • Unpin items to remove them from permanent storage
          • Reorder items by dragging them up or down
          • All editing features available (edit, delete, move to screener)

          📸 Screener Tab

          Purpose: Advanced capture and media management

          • 📷 Screenshot: Capture rectangular or circular areas
          • 🎥 Video Recording: Record screen areas with audio
          • 📁 Open Files: Click to open screenshots/videos in default app
          • 📋 Copy to Clipboard: Copy images to clipboard for pasting
          • 🗑️ Delete: Remove files from disk and screener
          • Move from other tabs: Transfer items from History/Pinned

          ⏰ LOGINNER Tab

          Purpose: Advanced time tracking and work session management

          📊 Session Management:

          • Start/Stop Timer: Track work sessions automatically with real-time counter
          • Manual Logging: Add past work sessions with custom dates and times
          • Click on Logs: Full customization - add descriptions and delete individual logs

          🏢 Project Management:

          • Click Settings: Access project management to select existing projects or create new ones
          • Project Categories: Organize work by different projects and clients
          • Project Values: Set hourly rates and conversion rates for billing

          📈 Reports & Export:

          • Monthly Reports: View detailed work summaries by month
          • Export CSV: Download reports in CSV format for Excel/accounting software
          • Export TXT: Download reports in text format for documentation
          • Total Time Tracking: See total hours worked across all projects

          🎯 Advanced Features:

          • Studio Desktop: Launch integrated project management application
          • Real-time Status: Visual indicators show active/inactive tracking states
          • Session History: Complete log of all work sessions with timestamps

          🎯 Advanced Features

          • Drag & Drop Reordering: Reorganize items in any tab
          • Multi-language Support: Interface available in 12+ languages
          • Auto-updates: Automatic updates with configurable frequency
          • Window Management: Always on top, minimize to taskbar
          • Data Persistence: All data saved locally and securely

          🔧 Tips & Tricks

          • Quick Access: Keep frequently used items pinned for instant access
          • Organization: Use screener for visual content, history for text
          • Search Efficiency: Use keywords to quickly find specific content
          • Time Tracking: Use LOGINNER for accurate project time management
          • Backup: All data is stored locally - no cloud dependencies
          • Privacy: Your clipboard data never leaves your computer

          ❓ Troubleshooting

          • App not responding: Restart Tilbi from taskbar
          • Screenshots not saving: Ensure you have write permissions to Pictures/Screenshots
          • Video recording issues: Check microphone permissions for audio recording
          • Data loss: All data is stored locally - check if files were moved
          • Performance: Clear old items if app becomes slow

          ⚠️ Important Note

          Drag & Drop Limitations:

          If you cannot drag items from Tilbi to certain applications or websites, this is due to security restrictions implemented by those programs/sites, not a Tilbi limitation. Many modern applications block drag-and-drop operations for security reasons.
